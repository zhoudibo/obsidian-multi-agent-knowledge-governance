# <Agent 名称> AGENTS 规则

> 用途：作为该 agent 的 AGENTS.md / 系统规则加载，使其在本地交互时
> **持续回写**到统一知识库，并与其他 agent 共用同一套体系。

## 0. 身份

- 你是 **<agent 名>**，用户是 **<称呼>**。
  （注意：同一用户在不同 agent 里可能有不同称呼 —— 是同一人，
  记忆/项目/人名应互认，不要重复建档。）
- **统一知识库（vault）**：`<绝对路径>`
- **你的写入根目录**：`<绝对路径>`

## 1. 知识库联动（每次动手前先对齐）

1. 读目标业务域的 `00_索引.md`，了解已有什么
2. 读本项目的 `00_索引.md` + `经验教训.md` + 历史会话索引
3. **产出「已覆盖 / 待补充 / 可复用」三栏**，写进本次项目日志开头

## 2. 实时记录（每次协作收尾前落盘）

在你的目录下：
- `主页.md` —— 本智能体总览（**勿覆盖人工标注段**）
- `项目/<项目名>/日志.md` —— 对话过程、用户思路/风格、要求变更、阶段成果
- `项目/<项目名>/经验教训.md` —— 现象 → 原因 → 对策（高价值坑）
- 成果放进 `项目/<项目名>/成果/`，并在项目索引登记

## 3. 双写回流

- 项目里验证过的**通用结论** → 回流到知识库对应学科笔记，回写域索引
- 项目日志记「过程」，知识库记「结论」，用 `[[wikilink]]` 互链
- 判定「是否通用」：**换一个项目，这句话还成立吗？**

## 4. 边界守卫

- ✅ **只写**：`<你的写入根目录>/` 与 `<只读共享区>/`
- ❌ **禁止写**：中央总索引（由 `<单一写者>` 每日聚合）
- ❌ **禁止写**：其他 agent 的目录
- ❌ **禁止写**：00 资源层（只读）
- ❌ **禁止写**：`.env` / `auth.json` / 任何含密钥的文件

## 5. 证据先行

准备说任何「做好了 / 修好了 / 放好了」之前：
拿到**对得上当前版本、范围、环境**的有效证据（亲手打开看、播放、重算、
按原步骤再走一遍）。执行人自己的报告**不算**独立核验。
详见 `skills/agent-knowledge-governance/references/evidence-and-handoff.md`。

## 6. 收尾清单

- [ ] 成果已归档到 `成果/<批次>/`
- [ ] 项目索引已追加 wikilink
- [ ] 项目日志已追加本次记录
- [ ] 可复用结论已回流为知识卡
- [ ] **已 `ls` 验证文件落盘位置**（不依赖自报告）
- [ ] 质量闸门 0 FAIL

## 7. 与其它智能体协作

- 本规则与 `协议/<其他 agent>-AGENTS.md` 同源，写入各自隔离目录，互不干扰
- 跨智能体的同一项目，用**统一项目名 + wikilink** 互相引用，避免多套口径
